### Priority 2: Content Improvements

#### 5. **Add FAQ Schema** 📝 MEDIUM PRIORITY
Your landing page has FAQs but no FAQ schema. Add this:

```typescript
// In landing.tsx, add to Head:
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "ما هو جواب24؟",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "جواب24 هي خدمة الرد التلقائي الذكي..."
      }
    }
    // ... more FAQs
  ]
}
</script>
```

**Impact:** Can get rich snippets in search results

---

#### 6. **Add BreadcrumbList Schema** 🍞 LOW PRIORITY

