# intentionally NOT disallowed here. Nginx returns 410 Gone for those URLs,
# and Googlebot must crawl them to see the 410 and remove them from the index.
# Disallowing in robots.txt would block the crawl and keep the URLs indexed
# (often as "Indexed, though blocked by robots.txt" in Search Console).

# signal.) Keep the Disallow list here in sync with the `*` group above.

# site — naming them changes nothing functionally, it just makes this file
