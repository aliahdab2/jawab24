# ONE group, several user-agents. Per RFC 9309 consecutive User-agent lines share
# the directive block that follows them, so the AI crawlers named here get exactly
# the policy everyone else gets and there is ONE Disallow list to maintain — not
# the eleven verbatim copies this file carried until 2026-08-22. (A named group
# does NOT inherit from `*`; that is why they sit in the same group rather than
# each getting their own.) Unnamed crawlers fall under `*`, so naming these
# changes nothing functionally — it keeps the policy auditable at a glance.
#
# Disallow = routes behind a login wall only: they render nothing but a login
# page, so crawling them is wasted budget. Pages that are public but `noindex`
# (/login, the /integrations hub, /pricing/scale, /checkout, /unsubscribe, …) are
# deliberately NOT listed — a crawler has to fetch a page to see its noindex.
# The list mirrors the auth-gated entries of EXCLUDED_ROUTES in
# frontend/scripts/validate-sitemap.js, which fails when the two disagree or
# when a Disallow would shadow a URL in the sitemap.
