# AutoReply.AI Mobile App

React Native mobile application for AutoReply.AI

## Tech Stack

- React Native (Expo)
- React Navigation
- React Native Paper (UI)
- Axios (API)
- AsyncStorage
- Push Notifications

## Development

```bash
npm install
npm start
```

## Build

```bash
# iOS
expo build:ios

# Android
expo build:android
```

## Features

- Facebook OAuth login
- Page management
- Template creation (multi-language)
- Inbox monitoring
- Push notifications
- Offline support
- Multi-language UI (AR/EN/SV/FR)
