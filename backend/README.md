# Jawab24 Backend

Backend API service for Jawab24

## Structure

```
/src
  /routes       - API route definitions
  /controllers  - Request handlers
  /services     - Business logic
  /ai           - AI integration
  /rules        - Rules engine
  /utils        - Helper functions
```

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm start
```
